# Cardoway Support

Official marketing, support, and privacy pages for Cardoway.

Current release behavior is maintained in `release-copy.json`. Run `python3 generate.py`
to regenerate the eight localized overview, support and privacy pages. These release
facts override the legacy copy in the generator (single-player, optional theme unlock,
and no saved in-progress game after a full relaunch).

- Website: <https://georgexu123.github.io/cardoway-support/>
- Support: <https://georgexu123.github.io/cardoway-support/support.html>
- Privacy: <https://georgexu123.github.io/cardoway-support/privacy.html>
